# Deal Chinese · 生意中文

Mandarin for doing business in China — numbers, prices, bargaining, phone calls.
Made for busy, tired learners: 5 minutes a day alone, 20 minutes a week with a Chinese friend, one real mission a week.

- **Today** — the learner's daily list (3 small tasks, streak).
- **Lessons** — units built around a sales call, starting with numbers and price traps.
- **Practice** — listen-and-say cards, number listening game (5 levels), number reader.
- **Teach** — 20-minute run sheet for the Chinese-speaking teacher, with English lines to read aloud.
- English by default, one tap for 中文.

Works without any key (progress stays in the browser). With a key from the owner, progress syncs to a
private GitHub repository. Want to use sync? Ask the owner for a key.

Run locally: `start.bat` (or `npm start`) → http://localhost:8775 · Tests: `npm run check`
